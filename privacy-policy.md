# Privacy Policy

_Last updated: July 31, 2026_

## XP Party HUD

XP Party HUD is a Chrome extension designed to display gameplay statistics for Baiak Idle.

## Information Processed

The extension reads information already displayed in the game interface, including:

- Hunt name
- Experience gained
- Loot obtained
- Supplies spent
- Monsters displayed
- Session duration
- Party information

## Local Storage

The extension stores locally in the user's browser:

- Hunt history
- XP/h records
- Gold/h records
- User preferences
- HUD settings

These data never leave the user's device.

## Data Collection

XP Party HUD:

- Does not collect personal information.
- Does not sell user data.
- Does not share user data.
- Does not use analytics.
- Does not use advertising.
- Does not track browsing activity.

## Remote Requests

The extension may access publicly available information from:

- Baiak Idle
- TibiaWiki

These requests are used exclusively to display gameplay information.

No personal information is transmitted.

## Donations

If the user opens the LivePix donation page, they are redirected directly to LivePix.

XP Party HUD does not process payments or collect financial information.
